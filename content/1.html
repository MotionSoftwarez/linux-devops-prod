1.1 What is Linux?

Linux is an operating system kernel. The kernel manages the computer's hardware and provides the foundation on which programs run.

A Linux distribution, such as Ubuntu, combines the kernel with system utilities, package management, libraries, and other software to provide a usable operating system.

1.2 Why do DevOps engineers need Linux?

Imagine a company runs a website on an Ubuntu server. Suddenly, users report that the website is unavailable.

A DevOps engineer may need to:

  • Check whether the web server is running.
  • Read error logs to identify the failure.
  • Check whether the disk is full.
  • Verify that the correct network port is listening.
  • Fix file permissions or a configuration problem.
  • Restart the service and verify that the website works.

These tasks are commonly performed through the Linux command line, often over SSH from another computer.

The goal of this tutorial is to make you capable of investigating these problems methodically.

1.3 Your first five Linux commands

You can run these commands on Ubuntu, most other Linux distributions, or a suitable Linux environment such as WSL.

Command Purpose Example result
pwd Show current directory /home/student
whoami Show current username student
date Show system date and time Current date and time
uname -s Show kernel name Linux
ls List directory contents Files and folders

Try them one at a time.

Linux terminal demonstration

Illustrative output

student@ubuntu:~$ pwd
/home/student

student@ubuntu:~$ whoami
student

student@ubuntu:~$ uname -s
Linux

student@ubuntu:~$ ls
Documents Downloads Projects

These are example results, not commands executed on your machine. Your output may differ.

What did you learn?

  • pwd tells you where you are.
  • whoami tells you which user is running commands.
  • uname -s identifies the kernel.
  • ls shows what is in the current directory.

1.4 How to read a Linux command

Consider:

ls -l /var/log

ls

Command

Lists files and directories.

-l

Option

Displays a detailed listing, including permissions, ownership, size, and modification time.

/var/log

Argument

Specifies the directory whose contents you want to inspect.

Important: /var/log is a common location for system and application logs. Some files require elevated privileges to read.

1.5 Real-world case study: A new DevOps engineer

Scenario: First day on an Ubuntu server

A team member asks you to investigate a server. Before changing anything, you need to establish your identity, location, operating system, and available files.

Your mission

  1. Identify the current user.
  2. Find the current directory.
  3. Identify the kernel.
  4. List the available files.
  5. Record your findings before making changes.

This exercise uses read-only inspection commands. No configuration changes are necessary.
